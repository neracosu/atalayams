# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En corto: trate a las demás personas con respeto, critique ideas y no a quien las propone, y ayude a que
quien recién empieza se sienta bienvenido. El acoso, los insultos y la publicación de datos privados de
otras personas no se aceptan.

Para reportar un problema de conducta, use el contacto de [neracosu.com](https://neracosu.com).
